description: File System Module
---

This module is designed to help users effectively manage and maintain all their related files and workspaces.
By creating a file system model, we provide users with a structured environment that allows them to easily organize and access their project files, ensuring that work is conducted in a neat and efficient manner.
Whether users are handling large projects or multiple small projects, this module can provide assistance.

## Folders
In this module, users can create project folders and organize related files in appropriate locations.
This way, users won't get lost in complex folder structures, but can quickly find the files they need, saving valuable time and effort.
Additionally, users can easily switch between different projects without worrying about file confusion or loss.
In practical applications, different projects may adopt different pre- and post-processing methods and may require handling multiple files.

## Workspace
To further improve work efficiency, we've introduced a special feature: marking a project as a workspace by adding a file with the .suan extension to the specified project.
Once a project is marked as a workspace, all modifications related to that project are automatically recorded in the .suan file.
The original intention of this design was to address the pre- and post-processing issues that users might encounter when dealing with multiple project calculations.
With the concept of workspaces, users can more conveniently manage these complex pre- and post-processing workflows, easily switch to the workspace of the required project, view and record all related modifications without affecting the files of other projects. Users can also handle multiple projects simultaneously without worrying about confusion or file loss. By simplifying file management and recording modifications, users can focus more on the projects themselves, improving work efficiency and quality.
