---
title: 工作台使用指南
description: 在桌面与 Web 打开会话、查看任务和检查计算结果。
---

STK 桌面和 Web 都从 **工作台** 进入会话，用 **任务** 查看运行状态，用 **结果** 检查已打开的文件或三维结果。切换这三个页面会保留当前会话草稿、任务选择和 Viewer 视角。发送消息、提交任务和打开结果各有明确的操作。

## 本地客户端

1. 在 **工作台** 打开页头的 **项目概览**，打开本地项目或创建示例项目。示例项目包含参数、合成场数据和一条已完成的分析。
2. 从左栏打开近期问答或智能体会话。点击 **已保存问答** 浏览完整列表。窄窗口先打开 **历史**。在 **项目概览** 中可打开项目表、文件和分析。在 **分栏视图** 中可并排查看多个工具。
3. 在 **任务** 选择连接和任务。对已发布可读结果的任务，点击 **在查看器中打开**。在结果页可展开 **来源** 查看绑定的任务和步号。

[Linux 快速上手](/quickstart/) · [macOS 与 Windows 构建](https://github.com/sijintech/stk/blob/main/desktop/QUICKSTART.md)

## Web 工作台

1. 打开部署的 STK 控制服务地址，用管理员签发的客户端配对码连接。连接后会进入 **工作台**，左侧可新建对话或选择历史。窄窗口使用 **历史**。
2. 在 **任务 → 运行环境** 选择节点和运行工作区，再从队列选择任务。首次选定工作区后，运行环境会收起，标题保留当前节点和工作区。需要修改时可以重新展开。
3. 从选定任务打开 **结果**，在 **结果文件** 选择文件并点击 **加载视图**，或在 **图谱** 选择预设并点击 **计算图谱**。展开 **来源** 可核对正在显示的任务、文件或步号。
4. 对发布了 `case/run.h5` 和 SHA-256 的成功 MuPRO 任务，在 **图谱 → MuPRO HDF5** 点击 **列出 HDF5 帧**，选择场和步号。多分量场的分量索引从 0 开始。点击 **打开所选 HDF5 帧** 后才加载新画面。

Web 的运行工作区来自已配对节点。桌面的本地项目管理项目表、文件和分析记录。切换客户端时，使用任务与结果的 **来源** 核对当前连接和对象。

[Web 与节点配对](https://github.com/sijintech/stk/blob/main/docs/hub.md) · [MuPRO 操作与 HDF5 结果](https://github.com/sijintech/stk/blob/main/docs/simulation-muferro.md)
