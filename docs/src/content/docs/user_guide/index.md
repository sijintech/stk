title: 工作台使用指南
description: 在桌面与 Web 打开会话、查看任务和检查计算结果。
---

STK 桌面和 Web 都从 **工作台** 进入会话，用 **任务** 查看运行状态，用 **结果** 检查已打开的文件或三维结果。切换这三个页面会保留当前会话草稿、任务选择和 Viewer 视角。发送消息、提交任务和打开结果各有明确的操作。

宽窗口把三个入口与历史放在同一条左栏。窄窗口的主导航在顶部，点击 **历史** 可继续撰写或打开以前的记录。

## 本地客户端

1. 在 **工作台** 打开页头的 **项目概览**，打开本地项目或创建示例项目。示例项目包含参数、合成场数据和一条已完成的分析。
2. 点击 **写问题** 直接回到当前项目草稿，或从左栏打开近期问答和智能体会话。点击 **已保存问答** 浏览完整列表。窄窗口先打开 **历史**。在 **项目概览** 中可打开项目表、文件和分析。在 **分栏视图** 中可并排查看多个工具。
3. 打开 **任务**。尚未选定有效工作区时，**运行环境** 默认展开。在 **运行位置** 选择连接。使用控制服务连接时，再选择 **计算节点**。在 **工作区** 点击 **新建…**，填写 **名称** 后点击 **确定**。当前任务页选中新工作区后，**新建任务** 默认展开。填写后点击 **提交任务**。
4. 改选已有工作区会保留 **新建任务** 的开合和草稿。手动收起后，新建工作区也会保留该选择。运行工作区存放所选连接中的任务输入和输出，本地项目可从 **项目概览** 管理。
5. 在 **任务** 选择任务。对已发布可读结果的任务，点击 **在查看器中打开**。在结果页可展开 **来源** 查看绑定的任务和步号。
6. 打开已收集的 MuPRO HDF5 帧后，从 Viewer 的 **来源** 输入从 0 开始的 X、Y、Z 网格索引，点击 **读取体素**。界面显示当前场、步号、分量及原始值。

[Linux 快速上手](/quickstart/) · [macOS 与 Windows 构建](https://github.com/sijintech/stk/blob/main/desktop/QUICKSTART.md)

## Web 工作台

1. 打开部署的 STK 控制服务地址，用管理员签发的客户端配对码连接。连接后会进入 **工作台**，左侧可新建对话或选择历史。窄窗口使用 **历史**。
2. 打开 **任务**。尚未选定工作区时，**运行环境** 默认展开。在 **执行节点** 选择节点。**项目** 列出该节点上的运行工作区，选择一个，或在 **新建** 旁的输入框填写名称（默认为“科学项目”）后点击 **新建**。首次选定工作区后，运行环境会收起，标题保留当前节点和工作区。需要修改时可以重新展开。之后可从队列选择任务。
3. 新工作区被当前页面选中后，**新建任务** 默认展开。标题可能先显示工作区 ID 的前 8 位，节点快照更新后再显示名称。点击 **运行解析场示例**，或在“自定义任务”下方编辑 TaskSpec JSON 后点击 **提交复核**。普通改选保留表单开合和草稿，手动收起后继续保持收起。
4. 自定义任务以 **新建任务** 标题中的工作区为目标，JSON 可省略 `workspace_id`。如果草稿中的 ID 与当前工作区冲突，表单会保留草稿并提示核对目标。可以编辑或删除该字段，也可在 **运行环境** 选定目标工作区。
5. 从选定任务打开 **结果**。成功任务只有一个可查看文件且文件选择仍处于初始状态时，**结果文件** 会预选它。确认文件后点击 **加载视图**。使用 **图谱** 时，选择预设并点击 **计算图谱**。展开 **来源** 可核对正在显示的任务、文件或步号。
6. 对发布了 `case/run.h5` 和 SHA-256 的成功 MuPRO 任务，在 **图谱 → MuPRO HDF5** 点击 **列出 HDF5 帧**，选择场和步号。多分量场的分量索引从 0 开始。点击 **打开所选 HDF5 帧** 后，可输入从 0 开始的 X、Y、Z 网格索引并点击 **读取体素**。读数对应当前显示的帧。

Web 的运行工作区来自已配对节点。桌面的本地项目管理项目表、文件和分析记录。切换客户端时，使用任务与结果的 **来源** 核对当前连接和对象。
