# 分析节点图检查

原生“分析图”编辑器用于检查当前 Viewer 的分析预设。它读取现有 `stk.graph/1`、节点目录和结果回执，
使用通用表格显示端口、参数、引用及输出。分析定义已可[保存到项目并重新打开](project-analyses.md)；
不可变输入绑定与明确执行使用独立的[分析运行记录](project-analysis-runs.md)。项目流程层和连线编辑仍在后续计划中。

## 打开与浏览

先在 Viewer 中打开运行目录、科学场文件或任务并选择预设，再选择 **视图 → 分析图**。
任一区域的编辑器下拉框也可选择“分析图”。Python 可以复用已协商的导航接口：

```python
stk.ui.activate_editor("analysis_graph", maximize=True)
```

单击节点查看右侧信息，或在右侧下拉框按节点 ID 选择并定位。中键/右键拖动、触控板滚动平移，滚轮或捏合缩放，
Shift+滚轮横移，Home 或“适应”显示整个图；F 或“定位节点”以正常大小居中选中节点，N 隐藏/显示右侧检查面板。
“三维”按钮回到已有 Viewer。以上操作不重新打开数据、不触发求值或下载，也不修改 SQLite 项目。

画布优先使用图内的节点位置，没有位置时按依赖层次排列。循环中的节点、未知类型、重复 ID、
不存在的端口或节点分别保留并显示诊断，不自动修复原图。多输入连接保留列表顺序及别名。
端口颜色帮助辨认类型；仅看连线或颜色不能判断类型兼容。
直接打开保存的分析时，编辑器独立读取本机节点目录，不要求先打开三维数据。
此目录读取不会推进 Viewer 中的待求值操作；读取失败显示原因，普通重绘不会持续重试。

## 当前参数与显示结果

四个标签分别检查；窄区域使用同一组选项的下拉菜单：

| 标签 | 图与参数的来源 |
|---|---|
| 当前参数 | 当前来源、预设定义、表单默认值与覆盖参数，以及 Viewer 请求的输出 |
| 已显示结果 | 发起该帧求值时记录的预设定义、原始提交参数及请求输出；切步缓存和预取保留该记录 |
| 保存的分析 | 从当前项目明确读取的分析定义，独立于 Viewer；不附带三维结果回执或解析值 |
| 冻结运行 | 从已读取的运行记录明确打开的冻结图、原始参数和输出选择；与保存定义及 Viewer 分开 |

参数变化或新求值失败时，Viewer 可能继续显示旧的成功结果。右侧明确区分配置一致、配置不同与无法比较，
并显示待求值、正在求值、缓存复用及错误。参数或时间步变化保留图的平移、缩放和节点选择；图定义变化重新适应布局。

现有求值请求发送预设 ID。本机记录的定义须与结果回执的 `graph_hash` 和 `graph_sha256` 核对，
两者有效、一致且匹配图语义哈希，才能把结果详情对应到图上。哈希缺失、格式错误或不一致时，
仍可检查本机提交记录，但界面会说明无法验证或不匹配，不标记节点执行、解析值或输出可用状态。

这项核对只覆盖图定义的计算语义，不验证源文件是否变化、远端数据内容或节点实现版本。
`step="latest"` 保留为原始提交值，求值器返回的具体步数显示在“结果解析值”列；二者不会被静默合并。
导入的 `.stkp`、payload 或结果目录没有原始提交图时，明确显示“没有可用图定义”，不根据哈希或现有预设推断。

## 参数与结果检查

节点参数表区分明确指定、节点目录默认值及缺失；明确的 `null` 不等于缺失。
选择参数后可以查看单位、`$param` 引用位置、图默认值和实际提交值。图参数表另列出对应回执中的解析值。
图参数 ID 属于该分析文档，尚未作为 SQLite 单元格或项目 UUID 关联。

输出表分别列出图声明的端口、是否请求以及对应回执已有的输出类型。未请求或没有结果的分支不会显示成已缓存，
检查界面也不会为了填充表格去执行该分支或获取额外 blob。
“回执记录了此节点的执行”描述原始求值；从 Viewer 帧缓存切换时会另外注明此次切换没有执行节点。

点击 **校验节点图** 才调用本机 `graph.validate`，校验当前检查的图和提交参数，不运行节点。
问题表显示节点、错误代码、JSON 位置及说明；画布的结构诊断与正式校验结果分开。
参数、图、目录、检查标签或桥进程变化时，旧校验响应失效，需要重新校验。关闭编辑器后迟到响应不会修改界面。

## 历史运行的冻结图

在“保存的分析 → 运行”中读取一条运行记录，再明确点击 **检查冻结流程图**。此操作只使用已经读取的记录，
不查询文件、不读取结果归档，也不启动节点。来源表保留运行与分析 UUID、原分析名称、来源修订、准备时间、
输入快照及计划哈希；文件映射表列出绑定、相对路径及内容哈希。参数保留原始 JSON 类型和明确的 `null`。

此视图固定在所打开的那份计划。后续选择其他运行、状态轮询、修改或删除保存定义、改变项目修订，
均不会替换它。返回保存分析可继续原来的参数与输出草稿；历史视图不提供保存、改名或准备新运行。
关闭项目、重开项目或更换桥会话会清除历史来源；恢复桌面布局只恢复检查模式，仍须明确读取并打开运行。

节点说明来自当前本机目录。这里的显式校验只检查当前环境下的图和参数，不验证历史插件版本、输入文件或归档。
历史视图因此不显示 Viewer 的解析参数、节点执行标记或结果可用状态；运行状态和校验过的归档仍在运行页查看。

## 当前边界

- 遵循现有 [graph v1](specs/stk-graph-v1.md) 的平面 DAG，不新增子图协议或项目数据库格式。
- 图超过 200 个节点时显示错误，不展开画布；每节点每方向最多展开 128 个端口及 128 个参数，
  另限制 4096 条连接、256 个输出和结构诊断。超出展开范围的项目显示省略数量，原图不被截断或改写。
- 值摘要、标签与嵌套引用检查有界；缩小到概览时隐藏细节，参数摘要仍可在表格查看。长值不是完整 JSON 导出。
- Viewer 的配置、求值回执和校验只在当前会话中；分析定义可通过项目分析文档明确保存。
  保存桌面布局只保留编辑器类型与检查标签，不写入科学数据、完整文档或项目打开指令。
  恢复“保存的分析”或“冻结运行”标签后仍须明确打开项目并读取相应记录；旧版本不认识此编辑器 ID 时沿用布局加载的兼容性处理。
- 不提供节点增加、删除、拖动保存或连接修改，也不替代 [Python 图 API](scripting.md) 的显式校验和求值。

验证结果按对应提交记录在[验收记录](runtime-validation.md)。macOS/Windows 真机鼠标、触控板及高 DPI 操作
仍按[工作台验收](workbench-acceptance.md)单独确认。

[标量分量体渲染](scalar-volume.md)提供明确的 `src → component → volume` 示例，
可用此页核对选择的字段、分量、单位及结果来源，再保存完整分析定义。
