# 在桌面使用本地文献

原生桌面的“文献”页管理本机文献库：导入你有权处理的 PDF，用本地检索模型检索，再打开命中的引用页并高亮原文。
它不需要先打开项目，也不连接外部模型或网络服务。每次读取文件、写入文献库或运行模型，都要你明确点击。
检索只返回原文证据和引用位置，不生成回答，也不代表检索质量已经评估。
接口与边界以[文献协议](specs/stk-desktop-literature-1.md)为准，模块位置见[桌面模块](desktop-modules.md)。

## 使用前需要准备的内容

以下条件要在桌面程序之外事先准备好。文献页不能安装依赖、下载模型，也不能更改解释器、模型接口或网络设置。

- **桌面程序与 Python 部分**：按[桌面指南](desktop.md)“安装”一节的 Python 部分安装并启动。
  文献服务使用桌面桥的 Python。解析和编码工作进程默认使用同一解释器，也可由宿主预先分别配置。
  解析环境需装有 STK 的文献解析依赖（可选依赖组 `literature`），编码环境需有本地模型推理依赖。
  依赖缺失时，对应操作会报告不可用，不会自动安装。
  如果桌面桥不支持文献功能，页面只显示“请连接支持本地文献的桌面桥。”
- **本地检索模型目录**：本机上已有的模型文件夹，其清单须对应文献协议列出的已知模型配置，
  例如 `e5-small-cpu-f32`。任意模型名不会被接受。目前的界面验收只用过 E5。
- **PDF 文件**：本机上的文件，并且你有权导入，可以是开放获取文献或本人创作的文档。
  路径须写完整的绝对路径，不能含 `..`。“PDF 文件”和“本地模型目录”都是文本框，没有“浏览…”按钮。

本页各文本框输入后按 Return 确认，再点击对应按钮。

## 进入文献页

1. 在默认工作台点击顶栏的 **文献**；也可以在“工作台”页“其他”区域点击 **文献**。
   不需要打开项目，进入页面本身不读取文件、不运行模型，也不向文献服务发送请求。
2. 页面分为 **阅读**、**文献库**、**检索模型**、**历史** 四个分页。
3. 点击页头的 **刷新**，读取现有文献库列表和模型选择状态。刷新前，库列表处会提示先刷新。

## 创建或选择文献库

1. 切到 **文献库**，填写“文献库名称”，点击 **创建文献库**，再点击 **打开新建文献库**。
2. 已有的库刷新后列在“选择文献库”下，点击库名即可选中。
   选中某个库后，阅读页的检索范围会重置为仅含这个库，并列出它的文献版本。

最多可以管理 8 个文献库。名称、标题和检索内容各限 256 字节。

## 复核并导入 PDF

导入分两步：先复核，再由你明确确认导入。

1. 在选中的库下填写“PDF 文件”（绝对路径）和“文献标题”。
2. 在“授权依据”中选择 **开放获取** 或 **本人创作**，填写“授权证据”（例如开放获取许可说明）和“批准人”。
3. 勾选“我确认有权导入并处理此文献。”，点击 **复核导入**。
4. 核对复核结果中显示的路径、标题、文件 SHA-256 与字节数以及授权证据。确认无误后点击 **导入已复核 PDF**。

“导入已复核 PDF”只采用屏幕上正显示的那一次复核。复核完成后，若修改任一导入字段、授权依据或勾选框，
这次复核即作废，须重新复核。复核本身不导入文件，也不解析内容。

## 解析版本

导入完成后，新版本会自动选中。点击 **解析所选版本**，解析 PDF 文本。
解析与下一步的检索索引是两个独立步骤。点击 **刷新文献版本** 可以重新列出该库的版本，每项标明“可用”或“授权已撤销”；
超过 20 项时用“上一页 / 下一页”翻页。

## 复核和选择检索模型，构建索引

1. 切到 **检索模型**，在“本地模型目录”中填写准备好的模型文件夹，点击 **复核模型文件**。
   复核只校验文件和运行环境，不加载模型权重。
2. 核对显示的目录和指纹，点击 **选择已复核模型**。页面随后显示“已选择本地检索模型。”
   选择模型本身不会构建任何文献库的索引。
3. 点击 **构建所选文献库索引**。它为“文献库”分页中当前选中的库建立检索索引，在 CPU 上可能需要数分钟。

库里导入或解析了新内容，或更换了检索模型之后，要检索这个库都须重新构建索引。

## 检索并打开引用页

1. 切到 **阅读**，点击 **刷新**。在“文献库”分页选中的库已默认勾选在“检索范围”中，不要再点它，否则会取消勾选；
   需要时再勾选其他库。
2. 在“检索内容”中输入问题或关键词，按 Return 确认后点击 **检索**。
   若检索范围或模型尚未就绪，检索按钮不可用，页面会提示缺少的前提；首次检索前，所选库还须已构建索引。
3. 每条命中都显示为 **打开引用页 · 序号 · 页 N · 原文开头** 按钮，按钮下方是原文节选。
   节选最多显示 1024 字节，更长时会注明“当前为节选”。
4. 点击某条命中的 **打开引用页**。这一次点击会依次定位该引用、生成该页页图并高亮引用的原文字符，
   无需再点其他按钮。定位后，引用段落的完整文本显示在下方，较长时用“上一页 / 下一页”翻看。
   页图显示在阅读页下方，高亮叠加在图像上，不修改原 PNG。
   打开另一页时自动适配阅读区域。重绘同一已核验页图或切回阅读分页时，沿用该页的缩放和平移。

页图在现有视口中显示，部分窗口和布局下页面底部可能被裁切，目前不保证完整显示整页。

这次打开只在当前阅读页内有效。如果在完成前修改了检索内容或检索范围、离开阅读分页，
或者隐藏、移动、重开这个文献页，自动接续即结束，不会在之后自动恢复。
定位未成功时也不会接着生成页图。

### 单独重试

页面保留两个单独的按钮：

- **定位所选引用**：对当前选中的引用重新定位，并显示完整文本。
- **显示引用页**：定位成功后可用，重新生成页图。新页图生成前，旧页图会先被释放。

页图未通过校验时，页面会提示重新定位引用，再明确生成页图。

## 撤销授权

1. 切到 **文献库**，点击库名，在版本列表中点击要撤销的版本。
2. 点击 **撤销所选版本授权**。点击后，所有文献页中由该库得到的页图和定位文本会立即清除。
   之后的检索、定位和页图请求都不会再返回它的内容。点击 **刷新文献版本** 后，该版本标为“授权已撤销”。

撤销不删除历史记录。当前界面没有恢复已撤销授权的操作。

## 历史与原操作

**历史** 分页用于查看以前的操作，不能用来授权新的操作。

- **刷新操作记录** 每页列出最多 50 条，每条显示操作名称和状态，可以翻页。
- 选中一条后，**查询原操作** 读取它的最新状态，**读取保存结果** 显示保存的结果摘要。
  摘要是分页文本，省略了 PNG 字节和逐字几何，不会在阅读页重新打开页图。读取时会再核对当前授权。
- 历史中的复核结果不能用来导入或选择模型。选中历史条目会清除当前页面上的复核和授权勾选。
- 检索、定位和页图的保存结果，只能对当前页面中最近一次的同类操作读取。旧的检索结果需要重新检索得到。
- 页面若提示“原操作尚未确认”，请先在历史中查询原操作，再开始其他操作。
  导入回复丢失时，可以在“文献库”分页的“原文献库导入操作 ID”中填写原导入操作 ID，点击 **检查原导入操作**。

当前界面不提供清理历史或释放存储额度的操作。

## 表单草稿与工作空间

- 表单中任何非空文字（包括已经检索过的检索内容）和已勾选的授权都算未保存草稿。
  有草稿时关闭或替换这个页面会被拒绝，并提示先保存或明确丢弃；点击 **丢弃表单草稿** 清空表单后才能关闭。
- 隐藏或移动文献页时，表单文字会保留，但授权勾选、复核结果和页图会被清除，后台已开始的操作不会因此取消。
  再次使用前，须重新勾选授权并复核。
- 文献页不会改动 Viewer 内容或其他页面中未保存的草稿。
- 保存工作空间时，文献页只记录所在分页、检索内容、选中的库和检索范围。
  PDF 路径、授权证据、模型目录和操作权限都不导出，恢复后也不会自动刷新、检索或运行模型。

## 当前范围与限制

- 目前只在 Linux X11 上做过实窗验收，使用合成 PDF、固定版本的 PDFium 和 E5 模型。
  macOS 与 Windows 的文献页尚待验证。
- 固定默认布局中，从检索命中到显示页图只需 1 次点击，这是针对验收夹具的测量。
  完整点击次数、起点和验收范围见[验收记录](runtime-validation.md)。
- 每次检索最多返回 20 条命中，页图长边为 1600 像素。
- 本页不提供基于文献生成回答（RAG）、付费文献、共享阅读或外部模型。文献库的导入和检索授权，也不等同于发表许可或对外共享许可。
