# 独立使用者视角审视（2026-10-06）

依据：两位不了解设计意图的审阅者，一位只看 `tests/wm/out` 与 `tests/app/out` 的界面截图，
另一位按新用户身份阅读文档并实际运行 CLI 与离线示例（只在临时目录操作，未改仓库）。
关键结论已抽查核实：默认布局、原始 JSON 外露、标量体范围显示、文档站内容。本文是问题记录与建议，不是已排定的计划。

## 总体结论

功能以许多安全、可追溯、测试充分的独立模块存在，但新用户难以发现或完成主流程
“建立参数扫描 → 运行 → 查看结果”：界面没有明确起点，主流程分散在多个编辑器和 Python 中，
内部机制（UUID、哈希、JSON 命令、桥、修订）直接展示给用户；真实运行需要 Linux Runtime 与 muFerro 许可，
且没有可离线试跑的运行路径。

已获认可：修订冲突检查、冻结运行与撤销等数据安全设计；三维 Viewer；AI 工作区窄窗口布局；
CLI 的项目、类型化表格、公式与单位、文件快照基础功能。

## 主要问题（按严重度）

## 建议优先改进

1. 修正标量体显示：自动范围显示实际数据范围，带符号数据的发散色图以 0 为中心（正确性问题，范围小）。
2. 以工作台为启动中心：按“打开项目 → 定义扫描 → 选择运行环境 → 运行 → 查看结果”引导，显示每步状态和下一步。
3. 补齐主流程操作：扫描生成器（每字段范围/列表生成行）、文件/目录浏览按钮、含运行环境选择的“运行选中行”，
   分析一键“运行并显示”，冻结/核验等步骤放入“详情”。
4. 默认隐藏内部细节（UUID、哈希、JSON 放进“技术详情”），统一中英文术语表，免责说明压缩为一行，界面内设置 API key。
5. 可试跑路径：内置假求解器与示例输出、可在终端/Jupyter 使用的无头 `stk`、一页 Linux 快速上手；更新文档站。
