## 实施主线

方案的中心是可信材料数据及其研究依据。STK 要支持一条可回查的链：
**需求与缺口 → 资料/计算/实测汇聚 → 加工标准化 → 专业鉴别 → 身份与版本关联 → 材料比较/标定/训练 → 决定与反馈**。
智能体组织工作，材料模型和计算方法产生有适用条件的结果，专家与独立验证为材料决定提供证据。
文献、计算、实测、专家判断、模型预测与合成数据分别标识；能检索的资料不自动成为可训练标签。

方案明确要求企业数据、全部问题、聊天、会话记忆及派生查询在厂内处理，**公开标注也不能使厂内会话外发**。
这个要求适用于该项目的部署方案；STK 通用版现有公开数据外部模型路径不能直接作为项目验收结果。
本轮只补设计和路线，不从脚本或代理修改现有端点、密钥、网络设置，也不放宽现有智能体执行契约。

## 最小数据关系与用途规则（待实现）

先复用项目的记录、字段、引用、修订、快照和运行归档，给业务对象稳定 ID；不为每个页面另存一份事实。
材料数据字典先用版本化 schema 描述，专用索引或数据库迁移只有在接口和恢复测试齐备后才发布。

| 对象 | 必须能回查的关系与条件 |
|---|---|
| 研究任务与目标 | 性能定义/单位、测试条件、基准、证据缺口、方法、任务状态与下一轮问题 |
| 材料与配方版本 | 计划与实际组成分别记录；链结构、分子量/分布、添加剂与相态；关联制备批次 |
| 制备批次、样品与分样 | 批次来源、工艺与热史、样品 ID/父样品、干燥/储存/接触/脱附履历；不同状态不能覆盖成一个值 |
| 方法与执行 | 实验/计算/分析方法及版本、仪器/软件、操作者、时间、输入条件、资源和输出摘要 |
| 原始资源与观测 | 文献位置或仪器/运行文件；原始值/单位/曲线；样品状态、时间轴、检测限、异常与重复测量 |
| 处理与复核 | 输出到原始资源及固定处理版本的关系；转换公式/参数、选区/排除原因、复核人/依据和历史 |
| 数据用途与质量 | 来源类型、缺测/待核/冲突/失败；验证对象/范围/方法、检索/比较/标定/训练的准入理由与适用条件 |
| 数据集、模型与评价 | 固定样本/标签及来源快照、训练/验证/独立测试划分、参数/种子/软件、指标/基线、模型版本与启用回执 |
| 候选证据与材料决定 | 候选、基准、原始曲线/计算、独立批次验证、适用边界、继续/调整/排除理由与后续任务 |

同一条测量可以形成多个派生指标，保留每条处理路径；纠错追加修订与原因，不改写已冻结的运行或评价。
缺测不补成零；异常、制备失败、低性能和冲突分别保留，是否排除与为什么排除是可审查的决定。
单位转换需要量纲与方法；材料组成、温度、时间、应变率、几何、热史或接触条件不匹配时，比较应提示差异。
文献记录区分已取得全文、仅摘要、待取得和访问/许可状态。没有定位与条件的摘录不能伪装成实测标签。
来源/单位已核、软件路径通过、计算收敛、实测重复性和预测的独立批次验证分别记录；一个“已验证”标签不能代表这些全部成立。

按样品/制备批次/配方族或来源研究分组冻结划分，避免同一曲线的点、分样、重复测量和相近模拟轨迹进入不同集合。
转换/特征统计只在训练集合拟合，测试集保留独立性；选择分组依据、时间边界与外部验证条件写入评价。
冻结样本清单及派生来源/祖先关系，不能仅靠可改名的分组标签；分组不足时不退回点随机切分声称独立。
独立测试集不反复用于调参、选模型或制定启用门槛，这些选择用训练/验证数据和预设策略完成。
记录测试访问与启用决定；已经用于后续选择的测试只作为历史回归，新的独立验收使用未参与选择的批次/条件。
计算与实测标签明确来源，不能直接混合后用同一误差声称实验预测准确度。

## 材料与方法的边界

- **纯 PET 是起点**：已交付模型仅干燥、中性、线性 COOH/OH PET，DP2–20；初始填充不是平衡试样。
  PET 基弹性体的共聚、共混、添加剂、交联、相区与界面需各自明确组成、参数和验证，不能改名复用纯 PET 结果。
- **目标需有条件**：Tg 关联热史/结晶与扫描方案；模量之外的韧性、黏弹、回弹、松弛和长期变形需要对应曲线与时间尺度。
  软件拟合通过与材料性质收敛分别验收；独立构型、链长/尺寸、热历史、采样和实测基准都留证据。
  多相材料可能有多个转变，不能强制用现有两段密度拟合给出唯一 Tg；保存 DSC 程序、DMA 频率/模式和取向。
  保存转变的定义、方法与相归属，DSC/DMA/MD 密度拐点不合并成同一标签；缺条件时只保留拟合及适用性待核状态。
  现有模量节点不计算循环耗散、残余变形、恢复、蠕变或松弛，MSD 也不描述宏观永久变形。
  这些目标需要完整加载—保持—卸载—恢复的曲线与时间轴，即时回弹与指定恢复时间后的残余变形分别记录。
- **接触行为另行验证**：记录接触介质组成、温度、时间、样品状态及脱附过程；气体、水/乙醇或混合介质需配套参数与验证。
  MSD 的扩散系数不能直接作为阻隔或渗透率；溶解/吸附、传输边界、厚度及适用模型需独立记录。
  区分干燥基准、吸收过程、含液平衡、脱附过程和再次干燥；质量下降也可能包含浸出，不默认等于脱附。
  所选原子 MSD、分子质心自扩散、传输扩散、溶解度、渗透率与试样透过率分别命名。
- **尺度转换有过程**：第一性原理只支持适用小体系与机制；结构统计、参数标定、代表体元与均匀化连向更大尺度。
  传递对象必须带物理量/单位、组成/状态、参数版本、适用范围与验证记录；连线不代表跨尺度结论成立。
  E2/E3 不默认覆盖通用有限元、注塑或拉伸吹塑；新增工业接口按任务选择稳定导出与登记方法。

边界的直接研究依据包括 [PET–PEO 多嵌段的结晶研究](https://doi.org/10.1016/j.polymer.2005.09.067)、
[PET 中低级醇的吸附动力学](https://doi.org/10.1016/j.polymer.2009.06.066)与
[PET 的 CO₂ 溶解/渗透/扩散研究](https://doi.org/10.1016/j.memsci.2013.10.009)。
这些研究支持记录组成、浓度、相态与过程条件，不为本项目预设材料性能、酒液配方或试验标准。

## 厂内部署与受控自动任务（待实现）

厂内方案需要统一的部署约束，覆盖文档解析/OCR、检索、embedding、重排、语言模型、材料模型、训练、Runtime、
插件、诊断/遥测、缓存、日志及备份；“机构内”标签不能代替对企业厂内设备/服务范围的实际核对。
所有问题、聊天、记忆、上下文和派生查询继承厂内边界，自动选模型和失败回退不得转到厂外。
部署策略从可信应用配置获得，文件、资料包或模型回复不能改变策略；端点和网络变更仍仅由桌面明确配置。
工具参数和附件也要经过同一边界检查，不能只检查问模型时的参数表标注。
桌面手动配置同样不得绕过已生效的厂内执行边界；桌面入口不代替部署授权和出口限制。

外部合作独立研究公共主题；审核过的资料包经受控导入进入厂内，保留来源、访问许可、摘要、条件、质量状态及处理版本。
厂内智能体不能把内部问题改写为“公开查询”发送到外部；需要内部数据的专家在企业控制环境中复核。
资料包中的文字作为数据处理，不执行其嵌入脚本或改变权限。
S4 联邦学习和 S5 跨机构借阅是 STK 的其他方向，**不作为本项目允许内部数据/聊天外传的前提**。

自主训练先只开放已登记的材料方法：企业通过桌面预设可用数据、工具、角色、资源/时限/次数、评价门槛和启用方式，
智能体据任务与新增有效证据提出或在授权范围内启动训练；不因每条记录入库就重训。
每次执行冻结数据、用途准入/专家复核、方法和策略版本，保留取消、重启核对、失败诊断、评价、候选版本、启用/拒绝与回退回执。
标签被纠错或证据被撤回后，新训练或启用重新核对；旧结果保留原快照并记录影响，不静默改写历史或沿用旧有效标记。
越权、缺条件、资源超限、独立评价不通过或重要争议进入复核；策略改变后不能继续使用失效授权。
先交付“训练评价后待启用”，再支持企业明确配置的自动启用门槛；语言模型不能自定科学合格标准。
角色权限、策略执行与训练工具需要新的版本化设计与测试，当前单写入项目和草案批准不能冒充企业权限体系。

## 交付顺序与验收节点

每个节点独立 critical review、修复、测试并更新四份交接/验收文档。业务字典与厂内边界设计可同 E1 并行，
不依赖真实客户记录的合成夹具先做；厂内边界验收前不接入企业内部数据或聊天。
已有 E1 桌面入口仍是最近的引擎开发节点，E2/E3 保持依赖顺序；本表不替换 S3 铁电/锂电合作方的数据讨论。

| 节点 | 开发产物与依赖 | 节点验收 |
|---|---|---|
| 1. E1 桌面与数据设计 | LAMMPS 导入/按引擎仿真视图；上述字典、导入样例与厂内调用清单 | 纯桌面导入→冻结→运行→收集→分析；旧 MuFerro 回归；字典/合成导入样例区分样品状态与来源，持久关系在节点 3 验收 |
| 2. 厂内执行基线 | 部署约束、受控资料包、本地模型/解析/检索/工具依赖清单；离线准备方式 | 本地桩覆盖公开表+厂内自由问题、内部端点失效后的外部回退；派发前拒绝且无厂外出流；子查询/工具/日志同验，当前设置不被自动改写 |
| 3. 数据加工与鉴别 | 批次/样品/状态、原始曲线与处理链、单位映射、质量复核与比较界面 | 至少两批样品、分样与干燥/接触/脱附三类状态的软件夹具可回查；单位错误/重名/缺条件/冲突保留；附件和修订不丢失；数量不作为材料统计标准 |
| 4. 可信材料证据 | 文献定位/厂内检索、专家意见、候选对照、证据报告；E1d/物性验证，按任务进入 E2 | 每个结论回查来源位置、样品、方法与原始文件；失败和独立验证进入证据包；目标材料/介质缺适用参数时记录缺口，纯 PET 不代验；拟合与材料验收分别报告 |
| 5. PET 数据集与评价 | 明确 PET 目标后扩展版本化契约；持久任务/模型资源；分组评价、适用范围与回退 | 来源/祖先/快照/划分可复算；无样品批次泄漏；独立测试不调参，与现用基线比较；拒绝/合成结果不当材料结论；重启不丢记录 |
| 6. 受控自主训练 | 新版智能体训练工具、角色/策略/资源冻结；依赖 2、3、5 | 有效新数据触发一次授权任务；越权/撤权/超限拒绝；取消和重开不重复启动；不达标保留诊断，启用及回退有回执 |
| 7. 多尺度与实测回流 | E2→E3；按任务登记代表体元/均匀化或工业软件接口；标定与独立批次实测 | 跨尺度参数带状态/单位/版本与验证；体元尺寸、独立形貌和边界条件收敛；对照实测、保留偏差；无接口可规范导入，不伪装自动集成 |
| 8. 移交与人员接续 | 完整依赖包、一致性备份/恢复、可读导出、操作培训与真实任务验收 | 无外网新设备恢复文件/方法/模型/历史；企业人员回查并继续任务，新增记录可再导出；物理材料成果另按任务书验收 |

编号表示交付范围，不是全部串行的调度：节点 3 的真实内部数据依赖 2，节点 5 依赖 3/4 的用途准入与目标定义，
节点 6 依赖 2、3、5 及有效企业授权；节点 7 依赖 4 和稳定的 E2/适用材料方法，可与 5/6 并行，
科学验证不必等待自主训练。节点 8 验收实际采用的整条路径及其完整资源，不能只恢复数据库。

阶段安排参考方案的一年周期：第 1–2 月落实目标/数据规则/环境，第 3–5 月形成首轮可信数据与任务闭环，
第 6–9 月开展候选、关键验证和模型更新，第 10–12 月独立验证、恢复迁移与接续。
方案计划于 **2027 年底**验收，但起算日与自然月排期未定；这是项目目标，不是 STK 现有工期承诺。

## 一条贯穿验收的真实任务

以一个已明确指标/条件/基准的 PET 基候选为单位：登记配方与实际组成、独立制备批次及分样，
记录干燥/接触/脱附状态与原始测试曲线；导入有位置和条件的资料，运行适用计算，保存处理与专家复核。
比较候选和基准，指出缺失/冲突；用合格数据快照训练或标定，保留独立评价、未通过候选和启用/回退依据。
形成继续/调整/排除的材料决定及下一轮任务，随后在厂内新设备恢复，由另一位研究人员接续第二轮并复用第一轮证据。
实际材料验证的批次数、状态程序与统计要求由方法和任务书确定，不由软件演练夹具数量决定。

演练必须同时覆盖：低性能/制备失败、异常/缺测/单位错误、重复资料、条件不匹配、外部回退失败、取消/重启、
评价不达标、标签更正/证据撤回、模型回退、缺失附件与备份恢复。先用明确合成的夹具验证流程，再用有许可和条件的真实数据验收材料任务。
平台安装、数据量、模型数和软件通过率不能代替材料验证。
提效只记录可比较任务的人工处理、等待、返工、有效证据产出与复用，不预填节省比例。
