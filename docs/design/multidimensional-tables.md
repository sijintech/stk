# 本地科研多维表格

2026-10-15：所有者要求以飞书多维表格的易用程度和功能为参照，并明确本轮先完成本地科研工作流。
本页区分本次实现、验收结果及后续范围；实际测试和 CI 记录在[运行验收](../runtime-validation.md)。

## 产品约定与模块

默认工作台直接显示表格，与 Viewer 并列。表格主体是网格；表、视图、搜索、新记录、新字段在顶部，
引用、公式、原始 JSON 和管理动作按需进入“记录详情”。普通编辑、排序、切换视图不自动最大化表格。
对照来源为飞书官方的[视图](https://www.feishu.cn/hc/zh-CN/articles/360049067931)、
[分组与筛选](https://www.feishu.cn/hc/zh-CN/articles/360049067904)和
[快捷键](https://www.feishu.cn/hc/zh-CN/articles/360049067880)说明；它们是体验参照，不代表 STK 已覆盖该云服务全部功能。

| 模块 | 职责 | 入口 |
|---|---|---|
| 通用表格控件 | 选格/矩形选区、键盘/IME、内联草稿、完整 TSV、列宽/冻结/列菜单、外部排序 | `stk_ui/src/core/table_grid.cc`、`TableSpec.grid` |
| 独立表格编辑器 | 网格与卡片布局、视图/字段/对象/文件交换表单、每实例草稿及延迟动作门禁 | `stk_app/src/table_workbench.cc`、`editors/table_editor.cc` |
| 只读桌面控制器 | 分页查询、视图/候选/来源读取、粘贴规划；句柄/修订/会话/弱生命周期检查 | `stk_app/src/table_workbench_state.cc` |
| 原有定义编辑器 | 字段/记录选择器、公式绑定、原始值、管理及参数扫描；接收外部网格可见 UUID | `stk_app/src/project_table_editor.cc` |
| 项目服务 | 类型约束、视图和选项、事务及撤销、对象适配、CSV/XLSX/JSON 预览与来源 SHA | `suan/project/field_types.py`、`table_workbench.py`、`object_refs.py`、`table_io.py` |

写入统一走既有 `project.apply` / 项目服务；没有第二份项目数据库、选择状态、调度器或模型调用入口。
普通 `TableSpec` 仍使用原有单行选择模式，其他编辑器不自动获得剪贴板写入或内联编辑。

## 本次功能

| 能力 | 实现与边界 |
|---|---|
| 网格编辑 | 单击选格，双击/F2/键入编辑，Enter/Tab 明确提交，Esc 放弃；失焦、切换标签和桥重连不提交草稿；异步失败保留输入 |
| 连续与批量操作 | 方向键、Shift 矩形、拖选、Ctrl/Cmd+A/C/V、Delete；完整值的带引号 TSV；服务器完整校验后预览/确认，一次修订、一次撤销；可明确追加缺少的记录，不推断新字段或公式 |
| 类型字段 | 原有文本/整数/数字/布尔/JSON，加日期、链接、单选、多选、项目对象；数值单位保留；选项以 UUID 存值，标签改名/重排不换标识，删除已使用选项拒绝且不写入 |
| 视图 | 项目中保存/复制/删除网格、看板、卡片视图；一击切换；字段顺序/显隐/宽度、冻结数、行高、分组、AND/OR 条件、多关键字排序；排序/分组/筛选先于分页 |
| 定义与来源 | 引用/公式格进入定义详情，F2+Enter 不会把公式变成常量；引用与绑定仍用表/记录/字段选择器；JSON 展示有界，复制导出使用完整值 |
| 项目对象 | 同项目的记录、已索引文件、冻结输入、分析、模拟、工作流；目标表和候选分页选择，明确查看来源；缺失/过期保持诊断；记录可定位，已索引文件可明确送 Viewer，分析/工作流可明确打开编辑器 |
| CSV / TSV | 原始预览、逐列类型与单位映射、SHA 固定后导入新表；导出当前视图的可见列、全表筛选与排序结果，仅创建新文件；CSV 是求值结果，不是项目备份 |
| 统计 | 当前页所选数值字段的近似和、有效数、缺测数及错误数；不把空值当零；整数单元格和排序保留 int64 精度 |
| 保护与恢复 | 每编辑器独立草稿，隐藏标签也参与保护；CAS 冲突保留输入；关闭、取消和新弹窗使旧写按钮失效；桥重连不重放写入；临时视图配置可随桌面布局保存 |

“搜索”只缩小当前页并明确显示 500 条分页边界；保存的筛选/排序作用于整表。搜索不隐式纳入 CSV 导出。
分组网格显示分组列并按组排序；看板按组分栏。卡片当前是字段摘要，没有虚构附件缩略图。
临时视图设置在当前编辑器使用，命名后明确“保存视图”才进入项目；视图名称和字段表单草稿受关闭保护。

## 常用操作

打开项目后，默认布局下方就是表格网格。旧自定义布局可用顶部“表格”入口进入；新建项目可直接使用新类型，旧项目先明确“备份并升级”。

- 单击选格后直接键入，或双击/F2 编辑；Enter/Tab 提交，Esc 放弃。失焦保留草稿，重新进入原格继续编辑。
- 先选粘贴锚点，Ctrl/Cmd+V 查看完整批次，检查类型和目标后点“应用”；撤销恢复整批。列不会自动增加。
- 点“视图”配置字段、分组、条件和排序，命名后点“保存视图”；之后点视图标签即可切换。看板和卡片中的“打开记录”返回对应记录详情。
- “+字段”选择类型和单位；单选/多选选项可改名及调整顺序。对象格从同项目候选中选择，“查看来源”后再明确打开对应记录、文件或流程。
- 工具栏“导入 / 导出”直接选择 CSV、Excel（XLSX）或 JSON。预览后明确导入；导出使用当前视图可见列与全表筛选结果，目标必须是尚不存在的文件。
  CSV/XLSX 逐列声明类型和单位，JSON 保留类型配置和缺测语义；公式导出计算值，详细限制见[表格交换](../project-table-io.md)。
  “更多 → CSV/TSV”继续保留兼容入口。全部窗口、参数和项目资源迁移使用[工作空间文件](portable-workspaces.md)。

## 格式 14 与协议增补

原有格式 13 项目仍可读取和查询，不自动升级。新强类型、字段配置及命名视图需要明确执行“备份并升级”。
新建项目使用格式 14；旧版本客户端不能打开它。升级先创建并验证数据库备份，保留旧编辑历史。
新增 `field_options`、`table_views` 两个关系，原 `fields` 五列形状保持不变，避免破坏旧撤销日志。
选项、视图及级联删除使用同一事务/撤销日志；只修改选项也使派生求值缓存失效。
升级本身不能撤销降级；升级后仍可撤销旧编辑。删除字段后，引用该字段的已存视图保留诊断并返回零记录，需明确修正视图；不自动更换字段。
PET 研究兼容格式 13 和 14，不借升级重新运行 MD。

协议仍为 desktop bridge v1；严格 schema 和来源检查同时适用。详细请求/响应见
[表格扩展契约](../specs/project-tables-14.md)。对象解析只读元数据，不能当作内容校验或启动模拟的授权。
冻结文件的元数据结果标明 `content_verified=false`；实际内容查看仍需既有快照校验路径。

## 剩余范围

- 单次粘贴最多 1000 条命令、1 MiB 文本，超限整体拒绝；UI 复制最多 100000 格、16 MiB。
  CSV 最多 8 MiB、64 列、10000 行，但导入仍受一次事务 1000 条命令限制；预览明确显示是否可导入。
- 查询每页最多 500 条、8 MiB。当前服务基于已有项目快照处理，并非百万行增量查询引擎；搜索和统计为当前页。
- 尚无填充柄/静止指针定时边缘滚动、非连续多选、附件缩略图、看板拖动改状态、日历/甘特/表单/仪表盘，
  也没有通用查找聚合字段或完整工作流自动化规则。本次对象选择不自动准备、提交、运行或下载资源。
- 多人实时协作、成员/行列权限、云端分享、评论与云端自动化未实现，按所有者选择留待后续服务设计。
- 本轮验收用公开合成数据和既有 PET 证据副本，未接入合作方内部材料；软件通过不代表材料物性验证通过。

后续按本地实际任务优先完善附件预览、关联聚合、批量填充和大表处理；每项继续记录固定起点、实际点击数、
键盘动作、数据结果和 Viewer/草稿保持，不以按钮存在代替功能验收。
