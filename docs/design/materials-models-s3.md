## 预测目标

### 铁电：P–E 电滞回线（所有者已定）

- **输出**：一条完整回线，按固定的电场网格取样：电场从 −E_max 升到 +E_max 的上升支与降回 −E_max 的下降支，各 N 个点（建议 N = 64），
  单位 P 为 μC/cm²、E 为 kV/cm；同时给出从回线读出的标量，便于检查与比较：剩余极化 P_r（E = 0 处两支之差的一半）、矫顽场 E_c（P = 0 处两支之差的一半）、
  饱和极化 P_s（E_max 处）。
- **输入（首版）**：只用标量参数，例如温度、电场幅值与频率，以及描述材料的少量参数（首版测试用朗道系数；真实数据时换成组分、薄膜厚度、应变等，由数据规范给出）。
- **为什么按固定网格取样**：模型输出定长向量，最简单的网络（多层感知机）就能学；不同测量的电场范围不同，取样前统一到同一网格（只在实测范围内插值，不外推）。

### 锂电池：容量衰减曲线（建议）

检索结果：机器学习用于锂电池的文献中，最集中的预测目标是**健康状态（SOH，按容量衰减定义）、剩余寿命与循环寿命**；
材料层面的目标（固态电解质离子电导率、正极电压与比容量）也常见，但分散在不同材料体系上，没有统一的数据形式。

- **建议目标**：放电容量随循环次数的衰减曲线 Q(n)，以 SOH = Q(n)/Q(初始) 表示，在固定的循环网格上取样（建议 0–2000 次、64 个点），
  并读出循环寿命（SOH 首次降到 80% 时的循环次数）。它和 P–E 回线一样是一条曲线，两个模型可以共用同一套“参数 → 曲线”的链路。
- **输入（首版）**：循环条件（充电倍率、放电倍率、温度、放电深度）与电芯描述（正负极体系、标称容量）；真实数据时可加入前若干次循环的特征（文献中常用前 100 次循环预测寿命）。
- **备选**：只预测标量循环寿命（更简单，但只用一个数，不能显示衰减过程）；或材料层面的离子电导率（需要组分或结构描述符，和思劲的相场工具关系较远）。

## 测试数据（合成，标注为合成）

- **铁电**：单畴朗道–哈拉特尼科夫方程（ρ dP/dt = −(2αP + 4βP³ + 6γP⁵ − E)，α 随温度线性变化），在正弦电场下积分，得到带矫顽场与剩余极化的回线；
  纯 Python（numpy），每条回线毫秒级。它只代表“像回线的曲线”，不是相场模拟。
  以后的真实来源：STK 已有的 MuFerro 链路目前只接入温度与步数，没有外加电场扫描；如果 MuPRO 的铁电模块能做电场扫描，可以把它接成工作流，批量产生相场回线
  （需要所有者确认 MuPRO 是否支持、输入怎么写）。
- **锂电池**：半经验衰减模型 Q(n) = Q₀·(1 − a·n^z)，a 随温度按阿伦尼乌斯关系、随充电倍率增大，加少量噪声；同样纯 Python。
  以后的真实来源：合作者的循环数据；公开数据（如 Severson 等 2019 年《自然·能源》的 124 个 LFP/石墨电芯）只能在确认许可后用于验证，不随 STK 分发。
- 合成数据集在数据卡中写明 `synthetic: true` 与生成器版本，登记的模型继承这一标记；界面与智能体都不得把它们的预测当作材料结论。

## 链路（首版范围）

1. **数据集契约 `stk.dataset/1`**：一个目录，内含 `dataset.json`（目标种类 `pe_loop` 或 `capacity_fade`、输入字段及单位、取样网格、来源、许可、敏感级别、是否合成）
   与样本表（每行一组输入与一条曲线）。本地校验器检查单位、网格、缺失与范围，生成只留在本地的数据卡（样本数、各字段分布、曲线示例）。
2. **训练**：小型多层感知机（输入标准化 → 2–3 个隐藏层 → 定长曲线），按训练/验证/测试划分，早停；每次训练是一次可取消、有日志的运行，
   产物是模型文件与指标（每点平均误差、读出的 P_r、E_c 或循环寿命的误差）。首版在本机 CPU 上运行。
3. **评估门槛与登记**：测试集指标达到门槛才登记为一个版本（版本、训练数据摘要哈希、指标、是否合成、许可），可回滚到上一版本。
4. **预测**：给定输入返回曲线与读出的标量，并说明模型版本与它是否用合成数据训练；智能体可以调用（新工具，级别“读”，只在本机计算）。
5. **界面**：先只做脚本与后台服务方法；桌面显示数据卡、训练进度与回线对比图放在下一步。

迁移学习、联邦学习（S4）与 MuFerro 电场扫描都不在首版内；首版只证明链路可用，并把两个数据格式定下来交给合作者讨论。
