# 统一研究工作台

2026-11-10，所有者要求简化 STK，并让网站与本地客户端使用一致的界面。工作台从会话出发，用户可以直接进入任务或结果，再回到原来的工作。

参照 Synthrix `caec2b9` 中 `docs/home-conversation-unification-2026-11-06.md` 的主页面。它把首页、输入框、新会话、搜索和历史放在一个工作区。专业页通过来源返回同一会话。Codex 提供会话居中、工作区和历史靠边、详细工具按需打开的交互参照。Synthrix 后续文献顶栏调整用于文献页细节。

## 主页面

所有者在 2026-11-13 确认，Synthrix 的主要页面是 STK 网站与本地客户端共同的设计参照。两端用同一套页面层级、控件顺序和反馈。第一屏突出输入框，已有会话突出正文，历史保留在同一工作台。两端的空会话都用「从一个科学问题开始」引导。桌面聚焦工作台中的项目问答与智能体会话共用居中正文列。缺少上下文时在「准备问题」旁显示原因。桌面继续由用户分别准备和发送。

当前会话关联的任务与文件放在同一个按需打开的详情面板，参照 Synthrix 的任务和文件侧栏。宽窗使用与窗口等高的右侧面板，窄窗从同一入口打开占窗口高度 80% 的底部面板。面板保持尺寸，较长的列表在面板内滚动。关闭后回到原会话、阅读位置和触发控件。面板只列当前会话已有且有权查看的引用。全局任务队列和结果继续从一级导航进入。本地打开项目、配置模型、选择运行节点等前置操作按各端能力出现在需要它的地方。

Web 从已保存会话的「关联任务」读取 Hub 的提交回执。收到同工作区的有效回执后，详情显示 Runtime 任务 ID 和「查看文件」。从发布清单可以明确下载文件或预览支持的小型文本文件。原生从已有决定或回执的智能体运行卡片打开同名入口，显示本地工作流状态、冻结快照与产物名称。可从任务详情打开其冻结文件清单，预览支持的小型文本文件。两端在同一个面板中显示任务、文件和预览。文件和预览各提供一个返回上一级的入口，面板始终可以关闭。返回时恢复打开该层的控件焦点。原生保存副本仍待接入。 [Hub 会话接口](../hub.md#路由) [原生会话来源设计](native-conversation-references.md)

## 两端的目标结构

| 位置 | 内容与行为 |
| --- | --- |
| 工作区导航 | 按同一顺序提供**工作台、任务、结果**。宽度大于 700 逻辑像素时，导航与历史在同一条 144 逻辑像素的左栏。宽度为 700 逻辑像素及以下时，主导航移到顶部，从**历史**打开列表。桌面显示当前本地项目和近期问答，Web 显示当前 Hub 连接的会话。 |
| 主区 | 工作台显示会话和输入框。任务页先显示当前队列与运行状态，运行环境和新建表单按需展开，提交留在表单中。结果页显示选定的文件或三维结果。原生聚焦页头保留项目、任务刷新、结果打开与导出等当前页的操作。编辑器选择、技术标签和区域菜单在分栏视图中使用。一级导航只改变呈现，不触发执行、提交、保存或模型请求。 |
| 按需详情 | 从当前消息、任务或结果打开来源、参数、日志、文献与文件。原生聚焦会话将数据范围与模型设置收在同一个可展开面板中。返回时保留原对象和位置。节点、表格、Python 与多视图并列操作可从专业分析布局进入。 |

同一动作使用一致的名称、顺序和反馈。两端共用项目、任务和产物的身份规则。原生项目与 Hub 中某节点的 Runtime 工作区各有自己的身份与权限，界面明确区分。仅在对应端支持时提供该动作。宽屏空间优先给当前任务，窄屏保留所有一级入口。Web 使用现有样式变量，原生使用现有主题、字号和缩放。

两端的一级导航都用蓝色选中态标出当前页。其余页面入口使用平面样式，键盘焦点单独显示。桌面将分栏视图也作为次要入口呈现。

原生项目确认没有已保存问答时，聚焦主区在引导后呈现输入框和「准备问题」。从左栏选择「已保存问答」可直接打开完整分页列表与归档筛选。窄窗先打开「历史」。选中条目才读取该问答。没有近期问答接口的桥使用页内列表。

历史区域首个操作进入撰写。Web 的「新对话」打开本地会话草稿。桌面的「写问题」复用当前项目草稿，将输入区移到当前页开头并聚焦。已选问答可以从撰写区一次点击返回，保留草稿和阅读位置，键盘焦点回到正文。准备和发送各由用户明确触发。

桌面聚焦智能体会话从侧栏进入近期记录，正文显示当前会话标题和内容。「智能体会话」展开完整列表和新会话入口。发送区显示模型不可用的原因，模型信息与用量可以分别从会话列表和记录展开。

从输入框按 Ctrl+Enter 或 macOS 的 ⌘+Enter 可触发当前主操作。Web 与桌面智能体会话提交消息，桌面项目问答准备问题供复核，发送仍由用户另行触发。Enter 保留换行。桌面会话输入框按 Esc 可结束编辑，草稿和输入焦点留在原处。 [键盘撰写验收方案](synthrix-workbench-next-acceptance.md)

原生聚焦会话的页头用「项目概览」打开分栏中的项目引导。从分栏顶栏直接返回「工作台」会恢复原会话实例和草稿，即使另一分栏也显示了会话。中途主动切换分栏标签后，按当前布局打开工作台。

两端在同一工作台中切换历史后恢复阅读位置。Web 在当前连接内分别保留已访问会话的阅读位置和草稿，首次打开时从顶部开始。用键盘打开历史会话后，宽窗和窄窗都把焦点移到正文，可直接按 PageDown 继续阅读。宽窗鼠标选择后焦点留在历史栏，方便浏览其它会话。桌面在当前项目打开期间为每个 AI 标签保留最近 32 条已保存问答的位置，新问答仍默认跟随末尾。

Web 与桌面智能体会话在用户明确发送后把最新消息带进视野。向上阅读时会停在当前位置，可用「跟随最新」回到末尾。Web 首次打开长篇已保存会话时也可直接使用该按钮。从正文按 Shift+Tab 可聚焦它，激活后焦点回到正文。桌面智能体会话按会话保留阅读位置，Web 切换时保留各会话的位置，后台读取与另一会话的迟到回复不会带动当前正文。

两端从历史入口按会话标题查找。Web 筛选已载入的标题，唯一匹配时按 Enter 打开并将焦点移到正文。桌面「搜索对话」在当前项目查询近期列表之外的已保存问答和智能体会话。首次 Enter 提交搜索，唯一匹配显示后可再按 Enter 打开。多条匹配时由用户选择其中一条。桌面窗口在宽窄布局之间切换时保留当前搜索、输入焦点与结果。归档问答仍可从已保存问答浏览，旧 Bridge 沿用原有历史入口。

从已选任务打开结果时，保留一级导航，在当前结果页展示该任务的来源。返回任务页沿用原任务、日志和未提交的表单。再次从同一任务打开已验证的同一结果时，保留画面、视角和当前步。选择另一任务或运行连接范围发生变化时，按当前来源重新打开。结果读取晚于返回时，用户留在任务页。

两端从已选成功任务点击「在查看器中打开」。当前运行连接确认发布了唯一的有效 VTI，且其余产物均为日志或文本说明时，一次点击打开该文件的切片。「来源」显示实际读取的文件。等待清单期间切页或更换任务会取消这次打开。重访同一任务已显示的结果时，保留画面。桌面在任务页等待清单时显示「列出结果文件」。

Web 进入「结果」后等待当前清单，已有读取由这次打开复用。当前视图为切片时沿用方向。用户明确填写过索引时沿用该索引，否则与桌面预设一样显示该方向的中间层。采用画面前核对发布摘要与返回的切片位置，「来源」显示画面的实际方向和索引。未满足直接打开条件时，若清单只列出一个可查看文件，且文件选择未编辑、还没有显示画面，预选该文件，用户再点击「加载视图」。多个文件由用户选择。已有选择或画面时保留当前设置和明确加载操作。

Web 的结果页状态栏显示「列出结果文件」或「正在加载视图」，来源详情同时标明已选文件正在加载。离开结果页时收起这项提示。若回到同一结果时原构建仍在进行，状态栏继续显示该构建的进度。

Web 清空切片的「索引」后显示「中间层」。下次明确打开或加载时，Runtime 按选定方向取中间层。用户填写 `0` 时显示该方向的第 0 层。编辑时保留当前画面和来源，构建成功后才显示新位置。

两端任务页在需要选择工作区时默认展开「运行环境」。首次选定有效工作区后收起配置，标题保留运行位置和工作区。若键盘焦点在即将收起的配置内，则移到「运行环境」标题。自动收起后失去所选范围会重新展开，重新选定后继续展开。手动展开或收起后沿用用户选择。

Web 在同一已配对标签页刷新后仍进入工作台。当前 Hub 的执行节点和项目列表确认原选择后，任务页直接显示对应队列，运行环境收起。断开连接或清空选择会忘记原运行环境。恢复只读取既有启动列表，任务由用户明确选中。

用户新建工作区后，创建成功的回执与当前运行范围一致且工作区已被采纳时，发起创建的工作台默认展开「新建任务」。后续普通改选保留表单开合与草稿，手动开合始终优先。任务由用户明确提交。Web 在节点快照列出新工作区之前使用回执 ID 显示任务范围，名称随快照更新。自定义 TaskSpec 使用当前工作区，填入其他工作区 ID 时保留草稿并提示核对目标。

原生同一区域的聚焦页面分别保存外层滚动位置。从所选任务打开结果后直接返回，两端在任务来源仍一致、入口可见时把键盘焦点交还给原入口。原生布局有多个任务标签时，直接返回仍恢复发起标签的日志流、详情页和滚动。Web 的日志捷径也使用这条规则。

窄窗打开历史时，菜单接收键盘操作，下方结果页保持当前视角和文件。按 Esc 关闭后焦点回到历史入口。

两端的主导航和历史共用位置、动作顺序和反馈。会话、任务与结果各有一个主区，当前对象的工具放在页内。原生应用菜单与 Web 的连接状态保留各自入口。

Web 会话和桌面聚焦项目问答共用居中的正文与输入列，宽窗上限为 880 逻辑像素，窄窗随可用宽度收缩。普通阅读时正文在输入区上方，可独立滚动。输入区的主要操作按文案所需宽度靠右。Web 的会话正文可从输入框按 Shift+Tab 返回，再用键盘滚动。桌面从「写问题」进入时，输入框仍先显示并取得焦点。已保存问答与 Hub 会话使用各自的身份和权限。

Web 将输入框、操作提示和发送放在同一张卡片内。用户消息靠右，助手消息从正文列左缘开始，角色名称继续显示。Web 历史滚动时，「新对话」和搜索留在同一个固定区，旧会话的键盘焦点滚到该区下方。 [Synthrix 页面逐区对照](synthrix-primary-page-parity.md)

Web 与桌面聚焦会话都在正文上方显示当前标题。Web 已确认会话的短 ID 可在历史条目与标题提示中查看。桌面项目问答沿用已保存问题的首条用户文字，智能体会话沿用历史标题。桌面问答继续就地显示状态、模型和适用操作。「请求详情」展开冻结数据来源及修订，可复制完整请求 ID 和上下文 ID。已完成的问答保留刷新和归档，待发送或运行中的问答呈现适用的发送、取消和恢复操作。

原生窄窗从任务打开新结果时，默认预设在首次绘制按可见宽度取景。作者提供的相机取景和用户调整的视角随结果保留，普通切页与缩放窗口沿用当前相机。屏幕内分类图例使用与文字相反明度的底色，便于在模型上辨读。

结果来源可在当前结果页一次点击展开。原生任务图显示已绑定的运行连接、工作区、任务和已显示步号，本地打开显示已记录的文件、目录或载荷标签。关闭详情回到同一结果与相机。

Web 的结果文件和图谱分别保留当前画面和相机。切换节点、项目或任务时清理旧图谱。离开图谱或打开窄窗历史时停止进度读取，撤回尚未发送的时间步调整。同一范围中已发出的计算可以完成，回到图谱时查看结果或错误。

Web 结果文件的等值面按点击「加载视图」时的等值计算。编辑后可继续保留这个输入，下一次明确加载时使用最新值。切片和向量视图可用数据中点初始化当前文件尚未编辑的等值。

Web 任务的「读取日志」打开当前任务的日志栏。首次读取标准输出，随后可在栏内切换「标准错误」和「标准输出」。日志栏保留最近一次确认的内容。点击「继续读取」从所选流已确认的源字节位置读取一块，补全跨块的字符和半行。空块且任务已结束时显示「已读完」。切换流保留键盘焦点，返回任务时焦点回到「读取日志」。

桌面任务详情直接显示所选任务的日志。订阅因最终错误停止时，日志区显示原因并保留已确认内容。可恢复的错误提供「重试日志」，一次点击从已读取的源字节位置继续两个流。

Web 图谱的「来源」显示当前画面实际计算的绑定、运行工作区与步号。新图层完成绘制后才切换来源并清除旧探针数值。结果读取或图层构建失败时，旧画面和来源一起保留。本地数据包用文件名标识。

对 MuFerro DAT 图层，Web 图谱的「查询原始值」按实际解析的步号，从该图层绑定的任务查询发布文件。自动算例目录有多个同名帧时，界面提示来源有歧义并保留画面。点选图层和修改坐标只更新界面。

桌面仿真页从已收集的 MuFerro DAT 运行一次点击打开结果。Viewer 首次读取预设时也沿用这次打开操作。验证结果和准备画面期间，若发起窗口切页、运行选择改变，或在 Viewer 中开始另一项操作，迟到的回执保留当前页面和画面。

Web 为已发布 `case/run.h5` 及摘要的成功任务，在图谱顶部提供可展开的「MuPRO HDF5」。桌面在仿真运行记录里提供已收集文件的入口。列出字段后，两端都明确选择场与步号，多分量场再填写从零开始的分量索引。点击打开时按发布摘要读取。来源记录当前实际显示的帧和分量。

打开 MuPRO HDF5 帧后，两端用「读取体素」按从零开始的 X、Y、Z 网格索引查询该场、步号和分量。Web 在图谱页显示控件，桌面在 Viewer 的「来源」中显示控件。更改坐标只编辑输入，离开结果或更换实际显示帧时丢弃在途回执。读数以原始类型显示，包括 64 位整数。

## 首片与后续顺序

1. 两端先接通**工作台、任务、结果**，分别复用原生 AI、Jobs、Viewer 和 Web 已有会话、任务、结果组件。原生可从保存的分析布局进入聚焦工作区，再恢复原分栏。Web 连接后进入工作台。切换时复用现有实例。
2. 统一项目与历史侧栏、来源返回和按需详情。接入共享项目能力后，再将已验证的项目操作呈现给相应的 Web 页面。原生文件、文献、脚本、仿真诊断沿现有明确入口工作，随后按任务情境移入工具与详情。
3. Web 连接后和桌面首次启动都进入工作台。桌面显式打开结果时显示 Viewer；已有布局继续按保存的分栏或聚焦页恢复。

## 验收

从各端固定起点记录窗口、语言、缩放、已打开对象和草稿。进入工作台、任务、结果分别测实际点击与键盘操作。验证返回后仍为同一会话及草稿、同一任务与产物、同一 Viewer 相机和时间步。验证切换产生的任务提交、模型发送和项目写入次数均为零。对网络断开、隐藏面板、刷新、旧保存布局与撤销导航做回归。结果来源、运行资源和数据权限沿用[跨端验收方案](distributed-workbench-acceptance.md)。

首次进入、会话历史、任务与文件详情的操作路径见[统一首页跨端验收矩阵](unified-home-acceptance.md)。
