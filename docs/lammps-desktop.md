# 在桌面导入和运行 LAMMPS

原生工作台复用 [LAMMPS 项目工作流](design/multiscale-engines.md)与现有运行记录。
导入、准备、提交、收集是不同的明确操作；打开项目、切换引擎、选择文件或读取结果不会开始计算。
当前仿真入口支持内置 MuFerro 和 LAMMPS；第三方引擎仍通过工作流或脚本使用。

## 导入和准备

1. 打开项目，在项目页展开“材料仿真”，将“计算引擎”选为 **LAMMPS**。
2. 选择干净的原始案例文件夹，包含输入脚本以及脚本引用的数据、势函数和 include 文件。
   “主输入脚本”只在目录只有一个候选时可留空；[PET 建模](pet-model.md)生成的目录有多份脚本，需明确填写
   `in.pet`、`in.tg`、`in.modulus` 或 `in.diffusion`。填写相对路径，不用绝对路径或 `..`。
3. 点击“导入并冻结案例”，在“分子动力学算例”表中选择并编辑该行。
   脚本使用的参数必须填写，未使用的参数保持空；数值单位以脚本的 `units` 为准。
   `real` 通常用 K、atm、fs，`lj` 是约化单位，不能把所有案例都当作 real 单位。
4. 选择已登记的 Linux Runtime（直连或 SSH），填写资源与执行选项，然后点击“准备选中案例”。
   高级选项可用 `program` 指定运行环境上的 LAMMPS 程序，或留空由模块登记/PATH 查找。
   本机分子建模模块的路径不一定是远程求解器路径；LAMMPS 不使用 MuFerro 的 `sdk_prefix` 等选项。
   反复准备相同输入复用原计划，不产生计算任务；要重算相同参数，先增加“尝试次数”。

两种引擎的执行选项在当前编辑器会话内分别保留，切换不会把 MuFerro SDK 配置送给 LAMMPS；重开软件后仍须核对资源设置。
切换引擎、项目或重开后，旧文件选择框及旧按钮回调失效。

## 提交、收集和离线查看

在“仿真运行”记录中加载刚准备的方案，核对冻结输入后明确提交，刷新任务状态。
选中 LAMMPS 运行后，“显示日志”和“收集并校验”按该运行的冻结引擎处理，
不按当前导入下拉框把历史运行当作另一种求解器。
只有 Runtime 任务成功才可收集；退出码 0、短轨迹或平均值本身不能证明材料性质收敛。

收集产生“分子动力学结果”表，保存单位制、实际热力学均值/末值、程序和文件摘要。
“打开结果行”定位当前运行对应的记录；“查看已收集结果”在本机核对文件、冻结输入、日志与表中摘要后显示结果。
后者不刷新 Runtime、不下载、不提交，Runtime 停止后重开项目仍可使用；改坏结果文件或摘要会明确拒绝。
这是热力学结果查看，原子/键和轨迹可视化属于 E1d，尚未实现。

Tg、模量和扩散使用现有[分析模板](lammps-analysis.md)与技能/工作流编辑器，
用户仍须选择来源、单位和拟合窗口。没有平衡、独立构型/尺寸/热史与实测对照时，拟合不作为材料结论。
PET 模型尚不包含气体、水/乙醇或弹性体新增组分的参数。

## 多行批次

展开“仿真批次”，选定引擎后加入当前行或全选该引擎案例；切换引擎会清空待运行成员，
已保存批次按引擎显示，历史记录保留在项目中。
旧的、不完整或第三方批次仍可查看、归档与恢复，但不能使用此面板的内置引擎执行控件。
“仅保存批次”只冻结选择；“运行所选行”明确保存、准备并提交。
保存后可逐行或整批准备、提交、刷新、取消与收集；重复提交复用各成员的运行身份。
LAMMPS 批次温度不强行添加 K，单位仍以脚本为准。

## 现有边界

输入只接受受支持的脚本与常规文件，不允许符号链接或能执行任意命令的 LAMMPS 指令；该检查不是沙箱。
干净输入上限 100 文件/256 MiB，单次收集上限 1 GiB；大轨迹需要另外规划传输。
本机建模与远程仿真仍须显式导入，不自动串联；远程模块安装、运行中监控事件尚未交付。
厂内项目须先完成部署边界验收，不能仅凭 Runtime/模型的“机构内”标签判定设备属于企业控制环境。

脚本也可用 `stk.lammps.view(run_id)` 读取同一份已校验的离线结果，
返回结果表/记录 ID、目录、单位、`thermo`、`qoi` 和文件清单；它不创建新的分析或模型请求。
