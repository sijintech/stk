# Synorder / STK 插件迁移验收

> 历史记录：本页记录 Synorder 集成原型当时的验收。STK 此后独立发展，桌面主线为
> [STK 桌面程序 stk-desktop](../../docs/desktop.md)（其前身 Blender 原生工作台已归档于标签
> `archive/blender-workbench-2026-09`），本插件暂缓。

本轮在 Linux x86_64 合成环境验证原生宿主、网页/手机布局及独立 Runtime。
代码分别落在 Synorder 产品仓库和 STK 的 `plugins/synorder`；未部署到实际 NAS，未配置云模型密钥。

## 已验证行为

- 独立 wheel 安装后，通过 `synorder.packs` 发现 STK；版本/文件摘要核对在导入能力代码之前完成。
- 插件提供同一份版本化视图，原生与网页分别绘制。拒绝未知控件、任意代码、重复 ID 和错误绑定。
- Chromium 390×844 手机布局实际填写配置、生成提议并确认提交；1440×1000 网页显示同一结果并加载 vtk.js 三维画布，无 JavaScript 错误或横向溢出。
- 配对后的原生 Bridge 读取同一结果。真实 Blender 窗口完成旋转、分区拖动、中文 Unicode 文本输入/提交。
- 重复提议、重复确认、执行监控重启不增加作业；关闭桌面连接后 Runtime 继续完成计算。
- 主动 WebSocket 节点重连后使用同一 Runtime；Hub 请求中没有 Runtime 令牌；离线时保留最后确认的状态。
- `stk.attach` 收录迁移前的 Runtime 任务，保持原远端任务编号，不再创建作业。
- 插件停用不设置已有任务的取消标志；隐藏新操作，保留锁定方法；在途任务阻止移除或更新版本锁。
- 固定解析场 `f=2(x+2y+3z)` 在 `[1.25,2.5,1.5]` 的原始数据探针为 `21.5`，绝对容差 `1e-12`，单位为无量纲。

## 图形测量条件

Blender 5.2.1 LTS，Mesa llvmpipe（LLVM 21.1.8，软件渲染），OpenGL 4.5，1440×1000。
显示的是实际计算输出的一张切片：48 个顶点、70 个三角形。
首次显示约 **1.27 s**；30 次强制重绘约 **63.6 次/s**；进程峰值 RSS 约 **435 MiB**。
空闲采样约 1.2 s，编辑器重绘 **0 次**。另有 Bridge 回归检查确保无变化时不改写画面文件。

这些是固定小数据、虚拟显示的软件渲染记录，不代表生产数据性能或显卡性能。
未测独立显存，未将强制重绘次数当作交互帧率。截图与机器可读原始记录位于 `validation/`。

## 回归与未完成的平台验收

STK 原有回归 **90 项通过**。插件安装/跨端/Runtime/节点测试及宿主回归结果见
`validation/test-results.json`；浏览器与原生分别保留 `browser-report.json` 和 `native-report.json`。

Windows、Apple Silicon macOS、AMD Linux、国产 GPU 与商业鸿蒙电脑的真机验收仍待执行。
鸿蒙 SDK/模拟器未在当前环境提供，未声称完成模拟器或真机移植。
本次中文测试验证已提交的 Unicode 文本，**未验证操作系统输入法组合窗口**。
剪贴板、缩放/休眠恢复、图形设备丢失，以及代表性生产数据规模的性能验收尚未完成。
此次插件原型不代表全部专业工具已迁移；STK 自有 Blender 原生工作台为桌面主线，Qt 界面保留为旧客户端。
